# My First Book, Coding Mastery: Building Programming Languages

My first book, "Coding Mastery: Building Programming Languages," has been available for about a month and a half.

### A Technical Reference

This technical reference covers programming languages, interpretation, lexing, and parsing. It is written for people with programming experience and a basic understanding of C++.

### Book Organization

The book has 15 chapters, beginning with computer communication and the history of programming languages. It covers grammar and functions, with examples and practical tasks at the end of each chapter.
